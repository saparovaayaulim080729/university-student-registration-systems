Use Case — Студенттерді тіркеу

Актер

Әкімші.

Негізгі сценарий

1. Әкімші жүйеге кіреді.
2. Студенттерді тіркеу бөлімін ашады.
3. Жаңа студенттің мәліметтерін енгізеді.
4. Жүйе мәліметтердің дұрыстығын тексереді.
5. Мәліметтер деректер қорына сақталады.
6. Жүйе тіркеудің сәтті аяқталғанын көрсетеді.

Қосымша сценарий

Егер міндетті мәліметтер енгізілмесе немесе электрондық пошта қайталанса, жүйе қате туралы хабарлама көрсетеді.

Нәтиже

Студент жүйеге тіркеліп, оның мәліметтері деректер қорында сақталады.
