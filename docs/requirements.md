Жүйеге қойылатын талаптар

Функционалдық талаптар

1. Жүйе студенттерді тіркей алуы керек.
2. Студенттің аты-жөнін сақтауы керек.
3. Студенттің электрондық поштасын сақтауы керек.
4. Студент туралы ақпаратты іздеу мүмкіндігі болуы керек.
5. Студенттер тізімін көрсетуі керек.
6. Студентті белгілі бір топқа тіркеу мүмкіндігі болуы керек.
7. Оқу пәндері туралы ақпаратты сақтауы керек.
8. Академиялық жетістіктер туралы ақпаратты сақтауы керек.

Функционалдық емес талаптар

1. Жүйені пайдалану оңай болуы керек.
2. Мәліметтер дұрыс сақталуы керек.
3. Ақпарат рұқсатсыз қолжетімділіктен қорғалуы керек.
4. Іздеу жылдам орындалуы керек.
5. Жүйе тұрақты жұмыс істеуі керек.
