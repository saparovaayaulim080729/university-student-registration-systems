# Университет студенттерін тіркеу ақпараттық жүйесі

Жоба туралы

Бұл жоба университет студенттерін тіркеуге арналған ақпараттық жүйені жобалауға бағытталған. Жүйе студенттердің жеке мәліметтерін, оқу ақпаратын және академиялық жетістіктерін сақтауға көмектеседі.

Жобаның мақсаты

Студенттер туралы ақпаратты бір жерде сақтау, іздеу және басқару процесін жеңілдету.

Негізгі мүмкіндіктері

* Студенттерді тіркеу.
* Студенттің жеке мәліметтерін сақтау.
* Студенттер тізімін қарау.
* Студент туралы ақпаратты іздеу.
* Оқу тобы туралы мәліметтерді сақтау.
* Пәндерге тіркелу ақпаратын басқару.
* Академиялық жетістіктерді сақтау.
* Деректерді реттелген түрде ұйымдастыру.

Қолданылатын технологиялар

* Git — жобадағы өзгерістер тарихын бақылау.
* GitHub — жобаны сақтау және басқару.
* SQL — деректер қорын құру және мәліметтермен жұмыс істеу.
* Markdown — жобаның құжаттамасын жазу.

Жоба құрылымы

* README.md — жоба туралы негізгі ақпарат.
* students.sql — деректер қорын құруға арналған SQL командалары.
* docs/requirements.md — жүйеге қойылатын талаптар.
* docs/use-case.md — жүйені пайдалану сценарийлері.
* docs/diagrams/er-diagram.png — деректер қорының ER-диаграммасы.

GitHub мүмкіндіктері

Жоба барысында Repository, Commit, Branch, Pull Request, Merge және Issues мүмкіндіктері пайдаланылады.

Қорытынды

Бұл жоба университет студенттерін тіркеу ақпараттық жүйесінің құрылымын жоспарлауға, деректер қорын ұйымдастыруға және GitHub арқылы жобаны басқару дағдыларын үйренуге арналған.
